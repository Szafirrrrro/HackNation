# Komponenty demonstratora

Wykaz obejmuje program analityka, przechwycenie stron i opcjonalne usługi. Wersje przetestowane w środowisku Windows obejmują Python 3.13.5, Streamlit 1.56.0, Playwright 1.65.2, Pillow 12.2.0, ImageHash 4.3.1 i scikit-learn 1.9.1. Zakresy zależności do instalacji są w [requirements-app.txt](../graph/requirements-app.txt) oraz plikach, które włącza. Polecenie `python -m pip inspect` podaje faktycznie rozwiązane wersje i metadane dla danej instalacji. Przy dalszej dystrybucji należy zachować noty licencyjne pakietów i ich dołączonych składników.
